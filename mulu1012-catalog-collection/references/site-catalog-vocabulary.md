# site_catalog 受控词表

来源：2026-07-14 从本地 WordPress `D:\projects\mulu1012\wordpress` 只读导出的 `site_catalog` 词项。

角色 meta：`mulu1012_site_catalog_term_role`

使用原则：

- 明确写有角色 meta 的词项优先。
- 无角色 meta 的词项，可按最近的有角色父项继承；遇到明确子项角色时，以子项为准。
- `WP test category ...` 测试词已排除。
- `featured_historical_sources` 词项不能作为 `primary_category` 使用。
- 下方 `site_catalog 层级词表` 同时列出主分类和特色史料，顺序按 WordPress 父子层级排列。
