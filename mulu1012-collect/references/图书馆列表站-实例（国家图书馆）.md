# 图书馆列表站采集实战：国家图书馆

拿这个站当模板改，比从零写快。要点不在正则本身，在**数据藏在哪里**——图书馆列表站的入口 URL、资源 ID、授权角色往往不在 HTML 文本里，而在 `onclick` 的 JavaScript 函数参数里。不知道这一点，采出来的记录会缺一半字段。

## 站点档案

| 项目 | 值 |
|---|---|
| 列表页 | `http://read.nlc.cn/outRes/outResList?type=全部` |
| 站点类型 | 图书馆列表站（无详情页，列表页即全部数据） |
| 分页 | 15 条/页，共 16 页，参数 `?pageNo={n}` |
| 总记录数 | 228（实采 227） |
| 字段上限 | 10 个 |
| 反爬 | 间歇性 502，需重试 |
| SSL | 只能走 HTTP，HTTPS 不可用 |

## 一条记录能提取的字段

| 字段 | 来源 | 正则 |
|---|---|---|
| `name` 名称 | HTML 文本 | `<span[^>]*style="overflow: hidden;">(.*?)<img` |
| `resourceId` 资源ID | JS `collect()` | `collect\('(\d+)'\)` |
| `intranetUrl` 内网URL | JS `openOutRes()` 第 2 参 | 见下 |
| `extranetUrl` 外网URL | JS `openOutRes()` 第 4 参 | 见下 |
| `roles` 授权角色 | JS `openOutRes()` 第 5 参 | 见下 |
| `resourceType` 资源类型 | JS `openOutRes()` 第 1 参 | 见下 |
| `description` 描述 | `title` 属性 | `<div class="txt"[^>]*title="(.*?)"` |
| `accessMethods` 访问方式 | 图标 `title` | `<img alt="" title="(局域网访问资源\|互联网访问资源)"` |
| `thumbnail` 缩略图 | `src` | `<img[^>]*src="([^"]*outResImages[^"]*)"` |

五参数一次取全：

```powershell
$outRes = [regex]::Match($c, "openOutRes\('(.*?)','(.*?)','(.*?)','(.*?)','(.*?)'\)")
# Groups[1]=资源类型  [2]=内网URL  [3]=固定值  [4]=外网URL  [5]=授权角色
```

## 采集脚本

顺序请求、每页重试三次、递增退避。**不要并发**——这个站并发就吃 502。

```powershell
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
$ProgressPreference = 'SilentlyContinue'

$totalPages = 16
$allItems = [System.Collections.ArrayList]::new()

for ($page = 1; $page -le $totalPages; $page++) {
    $url = "http://read.nlc.cn/outRes/outResList?type=全部&pageNo=$page"
    $html = $null; $retry = 0

    while ($retry -lt 3 -and $null -eq $html) {
        try {
            $html = (Invoke-WebRequest -Uri $url -UseBasicParsing -TimeoutSec 30).Content
        } catch {
            $retry++
            if ($retry -ge 3) { Write-Host "  [第$page页] 三次失败，跳过" }
            else { Start-Sleep -Seconds ($retry * 2) }   # 2s / 4s
        }
    }
    if ($null -eq $html) { continue }

    foreach ($li in [regex]::Matches($html, '<li>[\s\S]*?</li>')) {
        $c = $li.Value.Trim()
        if ($c.Length -lt 50) { continue }               # 空 li

        $name = ([regex]::Match($c, '<span[^>]*style="overflow: hidden;">(.*?)<img')).Groups[1].Value.Trim()
        if ([string]::IsNullOrEmpty($name)) { continue }

        $outRes = [regex]::Match($c, "openOutRes\('(.*?)','(.*?)','(.*?)','(.*?)','(.*?)'\)")
        $accessMethods = @()
        [regex]::Matches($c, '<img alt="" title="(局域网访问资源|互联网访问资源)"') |
            ForEach-Object { $accessMethods += $_.Groups[1].Value }

        [void]$allItems.Add([PSCustomObject]@{
            resourceId    = ([regex]::Match($c, "collect\('(\d+)'\)")).Groups[1].Value
            name          = $name
            description   = ([regex]::Match($c, '<div class="txt"[^>]*title="(.*?)"')).Groups[1].Value
            accessMethods = $accessMethods -join ' / '
            intranetUrl   = $outRes.Groups[2].Value
            extranetUrl   = $outRes.Groups[4].Value
            roles         = $outRes.Groups[5].Value
            resourceType  = $outRes.Groups[1].Value
            sourcePage    = $url
        })
    }
    Start-Sleep -Milliseconds 300
}

$allItems | ConvertTo-Json -Depth 3 |
    Out-File -FilePath (Join-Path $batchDir '01-国家图书馆.json') -Encoding UTF8
Write-Host "共采集 $($allItems.Count) 条"
```

## 这个馆踩到的坑

- **`extranetUrl` 可能是 sso 代理跳转链接**（`sso1.nlc.cn/...`）。这种不算资源入口，填充时不进 `入口页url`，改用 `intranetUrl`，并在 AI 评语注明「sso代理链接未收录」。填充脚本用 `--sso-host sso1.nlc.cn` 自动处理。
- **`sourcePage` 要逐条记下来**，不是整批共用一个值——它是备注列原始标签的一部分，也是日后复核的定位依据。
- **空 `<li>` 混在列表里**，长度过滤掉即可。
