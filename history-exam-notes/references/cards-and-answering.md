# 考点卡、答题与体检

## 一卡一考点

只有同时满足以下大部分条件时才单独建卡：

- 位于考试大纲范围内；
- 可以被单独命制为名词解释、简答、论述或史料分析；
- 对理解通史主线或组织答案有独立价值；
- 不只是另一个事件中的细碎人名、地名、数字或例证。

已存在更合适的卡时补入该卡，不因黄色标注或高频出现就机械“一词一卡”。人物卡是枢纽而非传记，论述卡是一条完整论证而非材料仓库。

## 建议元数据

若项目已有 schema，严格使用项目字段。新项目可从以下最小集合开始：

```yaml
---
断代: ""
类型: 事件
大纲章节: ""
题型: [名词解释]
真题: []
脉络: ""
来源: []
掌握度: 0
---
```

`来源` 列本卡实际使用的全部材料；`脉络` 指向通史页；`掌握度` 记录学习状态，不把知识状态搬到项目管理工具。

## 正文脊椎

所有卡共同遵循：定义一句 → 类型专属中段 → 影响/评价 → 易错 → 关联考点 → 来源 → 显式用户锁定区。

类型专属中段：

| 类型 | 中段 | 判断要点 |
| --- | --- | --- |
| 事件 | 背景 → 过程 → 影响 | 改革或政策没有时间线时，将“过程”改为“主要内容” |
| 人物 | 生平定位 → 主要活动 → 思想主张 → 评价与争议 | 只写此人在事件中的作用，细节链接到事件卡 |
| 制度 | 渊源 → 内容 → 演变 → 影响 | “演变”说明制度不是一次性事件 |
| 文献 | 成立背景 → 主要内容 → 影响 → 版本与解读 | 条款与关键词要准确，史料分析从版本差异切入 |
| 概念 | 提出与语境 → 内涵 → 流变 → 影响 | 定义必须放回论战或问题语境 |
| 组织 | 成立 → 宗旨与结构 → 主要活动 → 结局与评价 | 交代人、纲领、组织方式和终结原因 |
| 论述 | 总论点 → 判断式分论点 → 因果链 → 学术分歧 → 结尾 | 文件名即问题，全文必须由一条因果链贯穿 |

新建卡时优先使用项目模板，不临时发明章节名。若必须创建模板，按上表建立七类模板。

## 名词解释

目标是 150--200 字可默写密度，而不是堆满材料。答案至少包含：

1. 一句定性；
2. 时间、地点或关键人物；
3. 两至三个核心内容或过程；
4. 一句影响、性质或历史地位。

定义句必须能单独作为答题开头。数字、条款和专名只有在构成给分点时才保留。

## 论述题

- 采用总--分--总结构。
- 总论点是一句可争辩、可证明的判断。
- 每个分论点本身是判断句，随后用相关卡片和史实证明。
- 用 `A → B → C` 写出贯穿全文的因果链；写不出时，说明目前只是三组并列材料。
- 学术分歧逐条署名并给出处；结尾回扣总论点，不新起论点。

## 默写批改

1. 保留用户答案原文，不改写。
2. 按题型拆分给分点：名词解释看定性、时空、内容、影响；论述看总论点、分论点、史实、因果、结尾；史料分析先看是否概括和使用材料。
3. 区分史实错误、遗漏、表述含混和结构问题，不把风格偏好当成知识错误。
4. 错点必须回流到对应考点卡的“易错”，但不得进入显式用户锁定区。

## 知识库体检

重点检查：

- 大纲有而无卡片的考点；
- 真题考过而无卡片的考点；
- 没有被通史页引用的孤儿卡片；
- 同一史实在卡片间互相矛盾；
- 只有单一来源且缺少提醒的卡片；
- 长期未掌握的积压；
- 无法解析的内部链接和不符合类型模板的卡片。

体检只报告真实缺口。需要执行的任务进入项目管理系统，掌握度和易错继续留在卡片内。
