# 历史考研知识库分层

## 产物分层

已有项目结构优先。新建或迁移知识库时，可采用以下职责分离，而不必照搬目录名：

| 层 | 内容 | 典型权限 |
| --- | --- | --- |
| 大纲 | 考试范围和分类依据 | 只读 |
| 原始材料 | 教材、真题、OCR/MinerU 产物 | 只读，不在整理时回改 |
| 考点卡 | 可独立作答的知识点 | AI 可编译，保护用户锁定区 |
| 通史笔记 | 用户的整体历史叙事 | 用户与 AI 共同编辑未锁定正文 |
| 默写 | 用户原答案与 AI 批改 | 原答案只读，批改就近追加 |
| 工作流 | 方法、模板、工具经验 | 按项目约定协作编辑 |
| 索引与日志 | 编目、进度和操作记录 | 索引随摄入更新，日志只追加 |

这套分层的关键不是编号，而是避免三种混淆：不要把教材原文当成通史笔记，不要把通史长文复制进考点卡，不要改写用户默写原文。

## 推荐流程

### 材料

新教材或真题进入原始材料层，完成可搜索文本、页码和基本元数据整理。此阶段不等于复习完成。

### 摄入

读取一章主教材，对照大纲，建立或更新通史页和考点卡，并更新索引。只有把材料转化为可复习产物，才算完成该章摄入。

### 提问

先由索引和通史页定位，再深入卡片和原始材料。有复用价值的对比、专题综合或论证，可形成派生页；一次性问答不必全部入库。

### 批改

保留用户原答案，就近追加反馈；错误回流到考点卡“易错”，形成复习闭环。

### 体检

定期检查大纲覆盖、真题覆盖、孤儿卡、矛盾、来源缺口、链接和掌握度。体检结论与执行任务分开：知识状态住卡片，行动任务住项目管理工具。

## 保护与协作

`<!-- HUMAN -->` 是显式原文锁，任何文件中都不得改写、删除或移动。普通通史正文不按作者分块；AI 在用户授权的章节内直接协作编辑，版本历史记录修改来源。

默写区例外：用户答案始终保持原样，AI 批改使用项目指定的批注区或另行追加，不把修订直接写进答案。

## 表格判据

只有能自然增加第三列、且每格都短时才使用表格，例如“阶段/时间/战场/战役”。如果第二列实际是一段答案，应改成小标题和段落，因为答卷最终需要连续表达，脚注和嵌套材料也更容易维护。
