# 历史学考研笔记

目标不是把知识库写得博学，而是让用户能脱离教材口述通史、默写名词解释并组织论述答案。

## 开始前

1. 先读取当前项目的 `AGENTS.md`、说明文件、模板、索引和书单。项目本地规则、用户本轮要求和显式保护区优先于本技能。
2. 确认本轮产物：通史笔记、考点卡、默写批改、材料摄入或体检。不要把不同层的内容混成一页。
3. 确认主教材与章节边界。大纲负责分类，主教材负责知识主体；没有材料的范围不得假装已经覆盖。
4. 检查用户文字保护约定。`<!-- HUMAN -->` 区块一律不改写、删除或移动；普通未锁定通史正文可由用户与 AI 共同编辑，不另设作者分区。

## 共同原则

- **教材与标注共同编写**：先完整阅读主教材正文；若用户提供同书 Zotero 标注，则把教材 Markdown 与标注作为两条共同输入。前者提供连续语境和事实校核，后者把用户的选取、判断、结构、批注和问题直接带入正文。标注不能替代全文，但也不得降格为单纯的检索或取舍信号。
- **浓缩而非摘抄**：保留关键史实、分期、因果、转折和评价，压缩例证性细节；不得为了简短而丢掉教材的基本解释框架。
- **先保留层级**：初次建页或按教材重写时，核对目录与正文，保留教材可辨认的多级题签，包括解析工具漏成普通文本的题签。只有用户明确重组后才偏离教材层级。
- **线点分工**：通史页负责整体演变和考点入口，考点卡负责独立作答、完整论证、学术分歧与易错。不要在两处复制同一篇长答案。
- **判断先行**：论述段落先写判断，再用史实支撑；分论点必须是判断句，不是话题词。
- **出处可追踪**：主教材是未标注正文的默认来源，其他来源的直接引语和独特观点挂脚注；训练记忆必须标“未核”，数字和页码绝不猜。
- **面向输出**：每次改写后检查能否闭卷口述、能否写成 150--200 字名词解释、能否列出论述题的总论点和因果链。

## 按产物读取参考

- 新建或重写通史页：读取 [references/transhistory.md](references/transhistory.md)。
- 创建考点卡、论述卡、批改默写或做知识体检：读取 [references/cards-and-answering.md](references/cards-and-answering.md)。
- 使用 Zotero 颜色、处理 OCR、补充多来源或写脚注：读取 [references/sources-and-annotations.md](references/sources-and-annotations.md)。
- 新建知识库、迁移到另一套目录或判断各层所有权：读取 [references/knowledge-base.md](references/knowledge-base.md)。

只读取本轮需要的参考。若任务同时包含摄入整章、通史和卡片，则依次读取材料与标注、通史、卡片三份参考。

## 完成检查

- 主教材章节与大纲范围已经核对，来源缺口显式记录。
- 教材标题没有因解析缺陷被误删，也没有把“学术综述”等旁支误当正文层级。
- 通史页能够独立口述整体演变，链接到需要展开的卡片。
- 每张卡只有一个可独立作答的考点，类型结构正确，名词解释不过度堆砌。
- 所有内部链接可解析，frontmatter 与项目 schema 一致，保护区未改动。
- 索引、状态和只追加日志按项目约定更新；没有此类设施时不擅自创建复杂工作流。
